This repo will contain PoC setups around AI tried out by one2n employees.

The aim is to do contained trials of tools, dump them here and present them so that everyone in the organisation is aware of how the AI ecosystem is evolving.

### Contribution guidelines

1. Use Github project [AI bites](https://github.com/orgs/one2nc/projects/7) for task management.
2. Raise PRs - do not directly merge to main. Move the task to "In review" stage. It will be merged to main post review.
3. Add one folder per POC e.g bifrost/README.md where README.md contains your findings and bifrost/ contains a local setup showcasing the tool.
