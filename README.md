This repo contains PoC evaluations of AI tools tried out by one2n employees.

The aim is to do rigorous, beyond-hello-world trials of tools, document findings with evidence, and build organizational knowledge so we make informed adopt/reject decisions as the AI ecosystem evolves.

### Contribution guidelines

1. Use Github project [AI bites](https://github.com/orgs/one2nc/projects/7) for task management.
2. Raise PRs — do not directly merge to main. Move the task to "In review" stage. It will be merged to main post review.
3. Add one folder per PoC e.g. `bifrost/README.md` where `README.md` contains your evaluation and `bifrost/` contains a local setup showcasing the tool.
4. **Use [TEMPLATE.md](./TEMPLATE.md) as the starting point for every PoC README.** It enforces the structure we expect: real scenarios tested, architecture understanding, alternatives comparison, cost analysis, demo recordings, and a clear verdict. Shallow "I installed it and ran one command" write-ups will be sent back.
